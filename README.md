# SouthAfricaDemographyAnalysis

Summary:
This repository contains the code and analytical workflows used in _Recovering the pre-colonial population structure of Khoe-San descendant populations_. We analyze genome-wide data from 620 newly sampled individuals to reconstruct fine-scale population structure and ancestry in South African Coloured and Khoe-San descendant groups, quantify historical admixture, and infer sources of non-African ancestry linked to the Indian Ocean slave trade.

Scripts and materials included in this repository:
ADMIXTURE, GNOMIX, ancestry-specific MDS, UMAP, IBD networks, SPRUCE-RF pipeline 

PONDEROSA code available at https://github.com/williamscole/PONDEROSA


SPRUCE code available at https://github.com/evlynpless/SPRUCE-RF


MAPS softwate available at https://github.com/halasadi/MAPS
